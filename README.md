# Credit Debit Project
This Project focuses on analyzing credit and debit transactions patterns,customer account activity,monthly trends and High_risk transactions.
The objective is to Transform the Raw Financial transaction data into meaningful business insights using SQL and data analysis techniques.
#Key Metrics
Total Credit Amount,Total debit Amount,Total number of Transacctions,Monthly Transaction count,High_Risk Transaction count,Account Activity Ratio,Average Transaction Amount
#SQL Cocepts used 
Select,Order by,Group by,Having,Aggregate functions(SUM,COUNT,AVG),Case when statements,Join operators,Subqueries and CTEs Window Functions,Date and Time Functions
#Business Insights
Credit and debit transactions Patterns
Changes in transaction activity over time
Accounts with higher transaction volumes
Transactions that meet the Project's High_risk identification criteria
